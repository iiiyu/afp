# Maintenance Obligations

## Architecture Summary

This folder stores maintenance obligation schemas. The
`Afp.Factory.Maintenance` context tracks due operational work such as
dependencies, release follow-up, compliance, privacy, and support.

## File Inventory

- `maintenance_obligation.ex` - Persisted app maintenance obligation with category, status, priority, due date, recurrence, and completion note.
